# Self-hosted fonts

Baloo 2 (Ek Type), Plus Jakarta Sans (Tokotype), and Noto Sans Devanagari (Noto Project) are distributed under SIL Open Font License 1.1. Their complete license/copyright notices are included alongside the unchanged font binaries.

Font binaries came from the official Google Fonts CSS API and fonts.gstatic.com on 2026-10-05. The local stylesheet preserves variable-weight declarations, font-display: swap and Unicode subsets. Latin display/body subsets total 60,536 bytes; Devanagari faces load only when matching text is used. The four WOFF2 files total 296,876 bytes. There are no runtime external font requests.
